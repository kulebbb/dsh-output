# @kulebbb/dsh-output

[![CI](https://github.com/kulebbb/dsh-output/actions/workflows/ci.yml/badge.svg)](https://github.com/kulebbb/dsh-output/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

DSH（DeepSeek Harness）桌面端插件：在**右侧栏加一个「产出物」tab**，把当前这次对话产出的文件集中列出来。点一下就能预览，或者用系统默认应用打开、在 Finder 里定位。

会话里聊了半天，产出的文档、表格、图片散落在磁盘各处，找起来要翻对话记录、抄路径。这个插件把「这次对话到底给了你哪些文件」收进一个面板：跟着当前会话走，按类型筛选，点一下就能看。

> **平台**：DSH 桌面端（需要带右侧栏的版本）。Web 端也能用，但「用默认应用打开 / 在 Finder 中显示」只在桌面端出现。目前只在 macOS 上验证过。

## 功能

- **跟随会话**：每个会话一份独立列表，切换会话就切换内容。
- **自动汇总**：从会话记录里认出这次交付的文件——显式交付的、代码写出来的、脚本生成的、对话里提到的，都在。
- **筛选与搜索**：只显示有内容的类型，找文件可以直接搜文件名或路径。
- **点开就能看**：在右栏直接预览 Markdown、代码、图片、PDF、Office、HTML。
- **桌面动作**：用默认应用打开、在 Finder 中显示；纯 Web 环境自动隐藏。
- **深浅色跟随主题**：面板窄到 320px 也不会乱。
- 加载中、没有交付物、搜不到、请求失败都有明确提示，不会白屏。

## 安装

1. 侧边栏打开「插件」页 → 安装，填入仓库地址：

   ```
   https://github.com/kulebbb/dsh-output
   ```

2. 按提示**重启 DeepSeek Harness**（桌面端没有热更新，重启后插件才生效）。
3. 重启后展开右侧栏，点「＋」打开开始页 → 点「产出物」卡片。

> 从插件页安装不需要本地构建，构建产物已随仓库提供。

## 使用

- **打开面板**：右侧栏的「产出物」tab；或点右栏开始页的「产出物」卡片；或按 `⌘⇧O`（Windows / Linux 为 `Ctrl+Shift+O`，仅桌面端）。
- **看文件**：点任意一行，在右栏打开预览。
- **打开或定位**：行内按钮「用默认应用打开」「在 Finder 中显示」。
- **找文件**：顶部按类型筛选，或直接搜文件名 / 路径。

## 已知限制

- 文件被**重命名或移动**过（尤其是用 `mv` 改名）时，可能不会出现在列表里。
- 非常见扩展名（如 `.bin`、`.log`）不收录；常见的文档、表格、图片、音视频都支持。
- 模型在**收尾回复里提到**的文件也会被收进「对话中提到的文件」，所以仓库文档有可能出现在列表里。
- 列表显示的是**磁盘当前版本**，不是对话当时的版本。
- 单次最多显示 2000 条。
- 目前只在 **macOS** 上验证过，Windows 的路径处理没有端到端测试。
